TEN NIGHTS IN A HOTEL 10.2 — ОНЛАЙН-КООП (экспериментальная версия)

ЗАПУСК НА RENDER
- Root Directory: пусто, если файлы лежат в корне репозитория
- Build Command: npm install
- Start Command: npm start
- После загрузки откройте один и тот же URL оба игрока.

КАК ИГРАТЬ ВДВОЁМ
1. Первый игрок нажимает «ОНЛАЙН» -> «СОЗДАТЬ КОМНАТУ».
2. Отправляет код второму игроку.
3. Второй нажимает «ОНЛАЙН», вводит код и выбирает «ВОЙТИ В КОМНАТУ».
4. Ведущий (создатель комнаты) нажимает «НОВАЯ ИГРА» или «ПРОДОЛЖИТЬ».
5. Ведущий рассчитывает ночь и монстров; второй игрок получает состояние ночи и монстров.
6. Планшет и переключение камер остаются локальными у каждого игрока, поэтому можно смотреть разные камеры.

ОГРАНИЧЕНИЯ
Это экспериментальный кооперативный режим, не полноценная синхронизация всех механик. Ночь и ключевые состояния монстров передаются от ведущего; общие действия гостя (шторы, маска, действие у камеры) отправляются ведущему. Фонарик, поворот и камера личные. Некоторые визуальные эффекты, звуки, jumpscare и таймеры могут не совпадать идеально.
Если Render «уснул», подождите запуска сервера и обновите страницу. Для изменений на Render загрузите содержимое этого архива в репозиторий и дождитесь успешного deploy.
